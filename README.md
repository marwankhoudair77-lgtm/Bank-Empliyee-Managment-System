# Bank Employee Management System

A console-based Bank Employee Management System built using C++.

## Features

- Show All Employees
- Add New Employee
- Search Employee
- Show Employees By Department
- Show Department Statistics
- Exit

## Concepts Used

- C++ Fundamentals
- Struct
- Arrays
- Functions
- Loops
- Nested Loops
- Conditions
- Switch
- Strings
- Input / Output

## Departments

- IT
- HR
- Finance
- Loans
- Customer Service
